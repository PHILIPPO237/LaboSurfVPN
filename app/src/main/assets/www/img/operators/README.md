# Logos des operateurs (arriere-plan anime de la banniere)

Depose ici les logos, avec EXACTEMENT ces noms (un seul format par operateur suffit) :

- orange.svg   (ou orange.png / orange.webp / orange.jpg)
- mtn.svg      (ou mtn.png / mtn.webp / mtn.jpg)
- camtel.svg   (ou camtel.png / camtel.webp / camtel.jpg)

Conseils :
- Prefere le SVG ou un PNG a fond TRANSPARENT ; hauteur d'environ 100 px minimum.
- Le logo est affiche en petit (64 x 34 px max) et a moitie transparent : un logo simple se lit mieux.
- Tant qu'un fichier est absent, un macaron avec le nom de l'operateur s'affiche a la place.
- Rien d'autre a modifier : l'application detecte les fichiers toute seule (js/banner.js).
- N'utilise les logos officiels que si tu en as le droit et si le service fonctionne reellement sur ces reseaux.
