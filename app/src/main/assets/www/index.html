BIENVENUE 🚀

Bienvenue dans le LABORATOIRE DU FREE-SURF. 🌐
Notre plateforme vous permet de profiter d'un accès VPN lié à votre abonnement via l'app Labo Surf, avec un suivi clair de votre abonnement, de son renouvellement et de votre consommation — sans aucune configuration technique à gérer vous-même.

Vous voulez aller plus loin ? L'espace Revendeur vous permet de vendre à votre tour ces mêmes accès à vos propres clients, avec vos propres tarifs et votre propre suivi.

Trois niveaux d'accès sont disponibles : Gratuit pour découvrir la plateforme, VIP pour plus de serveurs et d'options, et Revendeur pour gérer vos propres clients. Un espace de discussion en direct est aussi disponible pour échanger avec les autres membres.

ÉVOLUTION DU PROJET 📈

Les grandes étapes qui ont façonné le Laboratoire.

Août

Les débuts

Première interface de l'application (9 août). Côté Panel : architecture multi-moteurs (Xray, Hysteria2, SlowDNS, ZiVPN, SSH, DNSTT), Config Generator, espace Revendeur, pages Mes options et Ma consommation.

1-7 sept.

LABOSURF PRO et les licences

Naissance de LABOSURF PRO, le serveur qui pilote les moteurs VPN, et du générateur de licences : une clé de licence ouvre l'installation de PRO (1 clé = 1 installation).

11-15 sept.

Moteurs et profils

PRO accueille TUIC, Hysteria2, WireGuard et le moteur freeway-gate, puis des profils nommés et la mise à jour par GitHub Releases.

20-23 sept.

Le Panel parle à l'agent

Le Panel dialogue avec l'agent de PRO par une API signée (HTTPS + Ed25519). Le moteur UDP LABOSURF devient réel dans l'application, avec le design sombre émeraude.

26-28 sept.

Premières versions officielles

Application 1.1.0 puis 1.2.0, première version officielle signée. Le 28 septembre : Panel 1.0.0 et LABOSURF PRO 1.5.0.

29 sept.-6 oct.

SSH, consommation et permissions

Moteurs SSH et SSH-SSL installés et testés sur le serveur, Panel 1.1.0 et PRO 1.6.0, configurateur de profils, clés d'activation renforcées, consommation mesurée par PRO et affichée dans le Panel et l'application, permissions individuelles des administrateurs.

9-12 oct.

Communauté et session unifiée

Live Chat communautaire du Laboratoire (thèmes, classement, rangs), refonte visuelle des espaces VIP, Gratuit et Revendeur, session unique entre le Panel et l'application, profils structurés émis par PRO et moteur SSH-HTTP.

13-17 oct.

Le cœur multi-moteurs

Application 1.3.0 puis 1.4.0 : le cœur multi-moteurs entre dans l'application (Xray, Hysteria2, WireGuard, TUIC, SSH, SSH-SSL, SSH-HTTP), avec « rester connecté » et le thème du profil. Le Panel sait désormais filtrer les profils selon les moteurs annoncés par l'application. Validation sur téléphone en cours.

PROJECT TIMELINE 📈

The major milestones that shaped the Laboratory.

Aug.

The beginnings

First app interface (9 August). On the Panel side: multi-engine architecture (Xray, Hysteria2, SlowDNS, ZiVPN, SSH, DNSTT), Config Generator, Reseller space, My options and My usage pages.

1-7 Sept.

LABOSURF PRO and licences

Birth of LABOSURF PRO, the server that drives the VPN engines, and of the licence generator: a licence key unlocks the installation of PRO (1 key = 1 installation).

11-15 Sept.

Engines and profiles

PRO welcomes TUIC, Hysteria2, WireGuard and the freeway-gate engine, then named profiles and updates through GitHub Releases.

20-23 Sept.

The Panel talks to the agent

The Panel talks to PRO's agent through a signed API (HTTPS + Ed25519). The LABOSURF UDP engine becomes real in the app, with the dark emerald design.

26-28 Sept.

First official releases

App 1.1.0 then 1.2.0, the first official signed release. On 28 September: Panel 1.0.0 and LABOSURF PRO 1.5.0.

29 Sept.-6 Oct.

SSH, usage and permissions

SSH and SSH-SSL engines installed and tested on the server, Panel 1.1.0 and PRO 1.6.0, profile configurator, hardened activation keys, usage measured by PRO and shown in the Panel and the app, individual administrator permissions.

9-12 Oct.

Community and unified session

Community live chat of the Laboratory (themes, ranking, ranks), visual overhaul of the VIP, Free and Reseller spaces, a single session between the Panel and the app, structured profiles issued by PRO and the SSH-HTTP engine.

13-17 Oct.

The multi-engine core

App 1.3.0 then 1.4.0: the multi-engine core enters the app (Xray, Hysteria2, WireGuard, TUIC, SSH, SSH-SSL, SSH-HTTP), with “stay signed in” and the profile theme. The Panel can now filter profiles by the engines the app announces. Phone validation in progress.
